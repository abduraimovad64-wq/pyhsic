Kondensator va gʻaltakdan iborat tebranish konturini yigʻing, tebranishlar davrini oʻlchang, kritik qarshilikni toping va konturni 3D da koʻring.

Tajriba maqsadi
  • Elektr tebranish konturi bilan tanishish.
  • Kontur xususiy chastotasini aniqlash.
  • Zanjirda tok va kuchlanish oʻzgarishini tahlil qilish.

Tebranish konturi

Kontur ketma-ket ulangan kondensator C va induktiv gʻaltak L dan iborat. Ideal LC konturda energiya yoʻqolmaydi, tebranish soʻnmaydi. Amalda gʻaltak simida aktiv qarshilik R bor, shuning uchun tebranish soʻnadi (soʻnuvchi garmonik ossillyator). Kondensator elektr maydon energiyasini, gʻaltak magnit maydon energiyasini saqlaydi va ular bir-biriga aylanib turadi.

Kirxgofning ikkinchi qonuni

Zanjirdagi barcha kuchlanishlar yigʻindisi nolga teng: ΣUi = 0 (I). Qarshilikli konturda:

UC + UR − Uind = Q/C + R·I + L·İ = 0  (II)

Bu yerda C = Q/UC, UR = R·I (Om qonuni), Uind = −L·İ. Tenglamani L ga boʻlib, Q̇ = I deb olsak:

Ï + γ·İ + ω₀²·I = 0  (III),   ω₀ = 1/√(LC),   γ = R/L

ω₀ — xususiy chastota, γ — konturning soʻnish koeffitsiyenti. Tenglama uch holga olib keladi:

ω₀² − γ² < 0

Aperiodik (siklsiz) holat: tebranishsiz, eksponensial qaytish. Qarshilik katta.

ω₀² − γ² = 0

Kritik soʻnish: tebranishsiz eng tez muvozanatga qaytish. Bunda Rkr = 2√(L/C).

ω₀² − γ² > 0

Soʻnuvchi tebranish: amplituda eksponensial kamayadi. Bu tajribada kuzatiladi.

Soʻnuvchi tebranishning yechimi

Kondensator boshlangʻich kuchlanish U₀ gacha zaryadlangan boʻlsa:

I(t) = I₀ · e−γt · sin(ωt)  (IV),   I₀ = U₀/(ωL),   ω = √(ω₀² − γ²)
U(t) = U₀ · e−γt · cos(ωt)  (V)

IV dagi sinus va V dagi kosinus tok va kuchlanish orasida 90° faza siljishi borligini bildiradi: kondensator toʻla zaryadlanganda tok nol, kuchlanish nol boʻlganda tok maksimal. (V) formula γ ≪ ω₀ boʻlganda yaxshi yaqinlashish; laboratoriyada aniq yechim ishlatiladi.

Tomson formulasi

T = 2π √(L·C)  (VI)  ⇒  L·C = Δt² / (4π²)  (VII)

Δt — kuchlanishning ikki qoʻshni maksimumi orasidagi vaqt (davr). Energiya: W = CU²/2 + LI²/2 ; soʻnmas konturda yigʻindi doimiy.

    Nega soʻnish kuzatiladi?

    Gʻaltak simining aktiv qarshiligida energiya issiqlikka aylanadi, amplituda e−γt qonuni bilan kamayadi.

    Nazariya va tajriba L·C qiymati nega farq qiladi?

    Gʻaltak oʻzagining magnit singdiruvchanligi tokka bogʻliq, shuning uchun L oʻzgarmas emas; qarshilik va vaqtni qoʻlda oʻlchash ham xato beradi.
